
# Smart Parking Management System

## Developed By
Sneha Rajashekhar Karidyamannanavar

## Project Description
Smart Parking Management System is a web-based project designed to manage parking slots efficiently.

## Technologies Used
- HTML
- CSS
- JavaScript
- MySQL

## Features
- View total parking slots
- Check available parking slots
- Book parking slots
- Store booking details
- Responsive website design

## How to Run
1. Open index.html in a web browser.
2. Select an available parking slot.
3. Enter customer and vehicle details.
4. Click Book Now.
